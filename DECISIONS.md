# Решения по проекту

## Стек: Astro + Tailwind CSS v4

Сайт — 7 разделов, часть из них (услуги, портфолио, карточки проектов) — однотипные страницы по шаблону, которых со временем станет больше. Чистый HTML начал бы дублировать шапку/подвал/карточки в каждом файле и плохо масштабировался бы при добавлении новых услуг или кейсов. Astro даёт компонентную структуру (Layout, Header, Footer, ProjectCard и т.д.) без клиентского JS-фреймворка: по умолчанию рендерится в статический HTML без гидратации, так что требование «быстрая загрузка на 4G» выполняется естественным образом. Интерактив (слайдер до/после, форма, фильтры портфолио) написан на ванильном TypeScript и подключается точечно через `<script>` в нужных компонентах — Astro islands тут не нужны, React/Vue не подключаем.

Tailwind CSS v4 (через `@tailwindcss/vite`, не CDN) — быстрая разработка дизайн-системы через утилити-классы и CSS-переменные (`@theme`), без лишних раннтайм-зависимостей: в v4 нет отдельного `tailwind.config.js`, конфигурация — прямо в CSS, что снижает количество файлов.

CMS не подключаем — контент захардкожен в `.astro`-файлах и вынесен в отдельные `const`-объекты там, где это упрощает повторное использование (список тарифов, шаги работы, FAQ).

## Фото группы ВК не спарсены

Прямой доступ к `vk.com/pro_remont76` и `vk.ru/pro_remont76` без авторизованной сессии отдаёт экран входа/регистрации (проверено и через WebFetch, и через `curl` с браузерным User-Agent) — контент группы (обложка, посты, альбомы) недоступен анонимному запросу. Использованы фирменные цвета из ТЗ (жёлтый/чёрный, уже выверены клиентом), а фото — SVG-плейсхолдеры с подписями и нужными пропорциями. Пункт «реальные фото» вынесен в `CONTENT-TODO.md`: клиенту нужно либо выгрузить фото из группы вручную, либо выдать доступ (сессионные cookies/экспорт) для повторной попытки.

## Порядок сборки

Следую п. «Порядок работы» из ТЗ: сначала дизайн-система + главная страница целиком, затем остановка для правок клиента, и только потом — остальные страницы. Это снижает риск переделывать 8 страниц из-за правки на главной.
