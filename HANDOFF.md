# Акт передачи — сайт «ПроРемонт»

Ремонт квартир и домов в Ярославле — корпоративный сайт на Astro и Tailwind CSS, 17 страниц.

- **Исполнитель:** Claude Sonnet 5
- **Заказчик:** Дмитрий, Ярославль
- **Стек:** Astro (static) + Tailwind CSS v4 + TypeScript, без CMS
- **Дата:** 2026-09-02, обновлено 2026-10-12 (переезд на Beget)
- **Статус:** работает на https://proremont76.ru (хостинг Beget), содержание заполнено реальными данными клиента

## Где смотреть

| Что | Ссылка |

| Локальный запуск | `npm install && npm run dev` → http://localhost:4321 |

## Хостинг и домен (2026-10-12)

Сайт полностью перенесён из Yandex Cloud на Beget, возвращаться в Yandex Cloud не планируется.

- Beget: аккаунт `mihainpx`, сайт `proremont76.ru` (id 9438224), папка
  `proremont76.ru/public_html`, домен добавлен и привязан к сайту (id 14771395).
- HTTPS — Let's Encrypt от Beget (заказан в панели, действует до 2027-01-10, продлевается
  автоматически). Сайт с SSL Beget обслуживает с IP `45.130.41.82`.
- `.htaccess` (в `public/`): 301 с http и www на `https://proremont76.ru`, своя страница 404.
- Домен зарегистрирован на reg.ru.
- Ресурсы в Yandex Cloud удалены 2026-10-12: CDN-ресурс, сертификат Certificate Manager и бакет
  `pro-remont76-static`. Осталась только DNS-зона (см. ниже).
- 2026-10-12 на reg.ru NS-серверы домена сменены на `ns1.beget.com`, `ns2.beget.com`,
  `ns1.beget.pro`, `ns2.beget.pro`. На момент записи реестр .ru ещё отдавал старые
  `ns1/ns2.yandexcloud.net` — reg.ru передаёт изменение с задержкой. Сайт при этом работает: обе зоны
  (Yandex и Beget) указывают корень и www на `45.130.41.82`.

Осталось:

- [ ] Убедиться, что реестр отдаёт NS Beget:
      `nslookup -type=NS proremont76.ru a.dns.ripn.net` (и `... 8.8.8.8`)
- [ ] Спустя сутки после этого удалить зону `proremont76-ru-zone` (id `dnsdmegdnkmmutp8alkn`) в
      Yandex Cloud DNS: `yc dns zone delete dnsdmegdnkmmutp8alkn`. Раньше нельзя — часть
      резолверов ещё помнит старые NS. Удалять строго по id: в том же каталоге зона sitomika.ru
- [ ] Предупредить коллегу, если он выкладывал этот сайт: бакета `pro-remont76-static` больше нет
